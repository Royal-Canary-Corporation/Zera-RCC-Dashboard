### Soros Reflexivity Theory

**Core concept:** Markets do not reflect reality neutrally. Participant perceptions feed back into reality, creating self-reinforcing loops. In a boom: rising prices → strengthened narrative → more buying → more rising prices. In a bust: the same loop runs in reverse, with the same speed and force.

**Key framework:**
```
Cognitive function:    x → y   (reality → perception)
Manipulative function: y → x   (perception → reality)
Reflexivity: when both functions operate simultaneously
```

**Critical insight:** "Every boom-bust sequence starts with a prevailing bias AND a prevailing trend. The boom is sustainable only as long as both reinforce each other. When the trend can no longer support the bias, the sequence reverses."

**Far-from-equilibrium condition:** When the gap between perception (market prices) and reality (economic fundamentals) becomes extreme, the system is inherently unstable. The larger the gap, the more violent the correction.

**Source:**
